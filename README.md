# MANGO Downloader

Portable desktop-приложение для Windows 10/11 x64. Пользователь распаковывает ZIP и запускает `Start.bat`; системный Python и установка пакетов не нужны.

## Что умеет программа

- проверяет подключение к MANGO OFFICE;
- получает расширенную статистику звонков за выбранный период;
- скачивает доступные записи в MP3 с защитой от повторной загрузки.

## Где взять credentials

Откройте **MANGO OFFICE → Виртуальная АТС → Интеграции → API коннектор**. Там доступны `vpbx_api_key` и `vpbx_api_salt`. Salt хранится только в защищённом Windows DPAPI файле текущего пользователя, а не в `settings.json`.

## Использование

1. Скачайте ZIP.
2. Полностью распакуйте папку.
3. Дважды щёлкните Start.bat.
4. При первом запуске дождитесь подготовки компонентов.
5. После этого откроется MANGO Downloader.

Затем введите API Key и API Salt, проверьте подключение, выберите период и нужные звонки и нажмите «Скачать выбранные».

## Для пользователя

Python устанавливать не нужно. Права администратора не нужны. Не запускайте `Start.bat` от имени администратора. Первый запуск source ZIP требует интернет для локальной подготовки компонентов; повторный запуск подготовленного приложения может работать без интернета.

Если приложение не может записывать в свою папку, переместите всю распакованную папку в доступное пользовательское место — например, на Рабочий стол, в Документы или Загрузки. Не повышайте права. Диагностика launcher находится в `logs/launcher.log`.

Рабочие данные находятся рядом с приложением: настройки и защищённые credentials — в `data/`, журнал приложения — в `logs/app.log`, записи по умолчанию — в `downloads/`.

## Для разработки и сборки

Нужен Python 3.12 x64 с pip. Установите `requirements/dev.txt`, затем запускайте `python -m app.main` или `python -m pytest`. На Windows `Build-Portable.bat` создаёт `dist/MangoDownloader-portable.zip` с Python Embedded, PySide6 и requests. Системный Python используется только при сборке; зависимости приложения устанавливаются в portable runtime из `requirements/runtime.txt`.
